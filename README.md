# JavaScript-ChatBotQR

A Node.js-based chatbot project designed for interaction and automation, utilizing JavaScript as its primary language. The repository appears to focus on integrating QR-based functionality, media sending, and user completion tracking.

## Features

- **Chatbot Core**: Main application logic resides in `app.js`, handling interactions and automations.
- **Media Sending**: Contains a `mediaSend` directory, likely supporting media transmission features.
- **User Tracking**: Maintains a log of completed users in `completed-users.txt`.
- **Dependency Management**: Uses `package.json` and `package-lock.json` for Node.js package management.

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/StebanJrb/JavaScript-ChatBotQR.git
   cd JavaScript-ChatBotQR
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the chatbot**
   ```bash
   node app.js
   ```

## Repository Structure

- `app.js` - Main application file
- `mediaSend/` - Directory for media sending features
- `completed-users.txt` - File for tracking users who have completed the process
- `package.json` / `package-lock.json` - Node.js dependencies
- `.gitignore` - Standard Git ignore file
